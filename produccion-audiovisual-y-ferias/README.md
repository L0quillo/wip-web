# Producción audiovisual y ferias WIP

Biblioteca general para campañas audiovisuales, videos corporativos, piezas de feria, audio, renders y futuras producciones. El nombre de esta carpeta no depende de una herramienta o agente específico.

Los documentos, prompts y recursos livianos pueden versionarse con Git. Los renders, archivos de control y videos finales se conservan en el almacenamiento compartido de OneDrive y están excluidos de Git por su tamaño.

## Proyectos actuales

- `video-feria-google-flow-2026/`: película corporativa de feria creada con Google Flow, compuesta por 34 clips y dos entregables finales.

## Convención para nuevos proyectos

Crear una subcarpeta con el formato `tipo-proyecto-herramienta-o-campana-AAAA`.

Ejemplos:

- `video-institucional-2027/`
- `stand-expocruz-2027/`
- `campana-calderas-arauterm-2027/`

Cada proyecto debe separar, cuando corresponda:

- `fuentes/`
- `assets/`
- `prompts-o-guiones/`
- `trabajo/`
- `control-calidad/`
- `entregables/`
- `archivo-control/`

No mezclar entregables finales con renders fuente. Conservar un `README.md` y un estado del proyecto para que cualquier agente pueda continuar el trabajo.
